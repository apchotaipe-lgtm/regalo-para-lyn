# Sorpresa para Aylyn

La página está en `index.html` y no necesita instalar Python ni dependencias.

## Abrir en tu computadora

Abre `index.html` en el navegador. También puedes usar la vista local que está corriendo en `http://127.0.0.1:8010/`; ese enlace solo funciona en tu computadora.

## Publicar gratis con GitHub Pages

1. Inicia sesión o crea una cuenta en GitHub.
2. Crea un repositorio nuevo llamado `regalo-para-lyn`.
3. Sube `index.html` al repositorio.
4. En el repositorio, abre **Settings > Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**; selecciona `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que termine la publicación. GitHub mostrará un enlace público con formato `https://tu-usuario.github.io/regalo-para-lyn/`.

Comparte ese enlace; no compartas `127.0.0.1`, porque solo abre en tu computadora.
